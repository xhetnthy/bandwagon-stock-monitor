## 蹲补货的实操方法

等限量版补货，光靠手动刷新效率太低，有效的组合是这几件事：

1. **收藏库存监控页**。官方 stock.bwg.net 或任何一个第三方监控站，有货状态一目了然 [S6][S7]。
2. **加入补货通知渠道**。搬瓦工优惠网提供补货通知页面和 QQ 通知群 [S5]；搬瓦工中文网历史上维护过多个补货 QQ 群和 TG 频道 [S2][S24]。通知渠道的具体群号可能随时间变动，以这几个站当前页面公布的为准。
3. **理解刷新频率的逻辑**。监控站普遍采用 5 分钟间隔刷新，依据是限量版补货窗口通常在半天到一天量级，5 分钟既能及时捕捉，又不会给服务器压力 [S3]。热门型号（比如 THE PLAN 系列历史补货）可能在几小时内清空 [S11]，所以有通知渠道就要尽快下手。
4. **看清缺货状态**。限量版缺货时页面显示 "Out of Stock" 或选项直接消失、置灰 [S17]。这里要特别提醒：不要相信任何声称“能内部渠道下单缺货套餐”的说法，这类说法通常是骗局 [S17]。

关于优惠也得说一句现状：搬瓦工目前停用并取消了全站通用常规优惠码——在其他商家因上游成本上涨而涨价时，搬瓦工选择维持原价，代价是优惠码这条路走不通了 [S17]。网上流传的所谓通用码，下单时自己验证一下是否还有效即可，别指望它。现在省钱的正规方式主要是选长周期计费：以 CN2 GIA-E 入门套餐为例，年付 $169.99 相当于每季度 $42.50，比季度付的 $49.99 一年省 $30 左右 [S5]。

## 已购的限量版，会因缺货续不了费吗

不会。搬瓦工的政策是已购套餐可以正常续费，库存耗尽只影响新购买，不影响存量用户，服务不会因为缺货被强制停掉 [S13]。两条建议跟着这个政策来：购买后及时在 KiwiVM 面板开启自动续费；偶尔关注官方公告，确认套餐续费策略没有变化 [S13]。
